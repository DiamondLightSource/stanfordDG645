StreamDevice support for the Stanford Research Systems DG645 digital delay generator.

This module is a StreamDevice based alternative to the delaygen module. The
delaygen module is asynPortDriver based and comes from the EPICS community
(SYNAPPS). It is probably better to put future effort there.

Version 2-0 onwards requires EPICS base 3.15 or later, and will not build on
3.14. For EPICS base 3.14, use version 1-3.
